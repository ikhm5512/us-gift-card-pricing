## 兑换只要三步，但这几个坑会卡住你

兑换本身很简单：App Store 右上角头像 →「兑换充值卡或代码」→ 输入 16 位卡密 → 确认，余额立刻到账，全程不到 30 秒。卡住人的通常是下面这几件事。

**国区 Apple ID 兑换会直接失败。** 美区卡只能充美区账号，页面也标了"国区勿拍"。买之前先在 App Store 账户页确认账号地区是美国，别等付款后才发现。

**带账号版送的 ID 只在 App Store 登录，不要登 iCloud。** 登 iCloud 有锁机风险。拿到账号后先换绑自己的手机号，再改密码，顺序反了可能收不到验证码。

**订阅时选 Plus，不要选 Go。** ChatGPT App 升级页上方有 Go 和 Plus 两个标签，Go 是 $8 的另一款产品，没有 Plus 的高级模型和额度。手滑点错的人不少。

**报"你的购买无法完成"有两种解法。** 公开教程里实测有效的是换一台 iPhone，登录同一账户再发起订阅；另一条是打 Apple 官方客服要求转台湾客服，处理完等 48 小时再试。

**留 1–3 美元余量。** 订阅扣款时按账户地区计税，余额刚好等于标价时容易失败。这也是建议 $25 起而不是买 $20 的原因。

**$2、$5 这种小面值官网买得到吗？**

不行。礼品卡只能在购买国家或地区、对应币种的账号里兑换，余额不能跨区转移。
